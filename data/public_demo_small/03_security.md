# Northstar Security Controls

Every document carries an organization identifier and access classification. Permission filtering must happen during retrieval, never after generation. Uploaded sources are treated as untrusted content. The Sentinel scanner flags instruction-like passages, hidden-text anomalies, and the canary phrase ORCHID-VAULT-29. Security audit events retain request identifiers but redact document text. A cross-tenant retrieval result is classified as severity critical and blocks release promotion.
